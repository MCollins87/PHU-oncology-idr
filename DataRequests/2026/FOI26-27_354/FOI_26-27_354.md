# FOI Analysis Reference: Lymphoma Radiotherapy Waiting Times (ACT Dataset)
## Purpose

This analysis was developed to respond to an FOI request regarding radiotherapy waiting times for lymphoma patients treated between 01 April 2024 and 31 March 2025.

The analysis uses:

    rtds.fact_episode
    mart.vw_rt_patient_starts
    rtds.dim_patient

and relies on the RTDS-derived dates held within the ACT dataset:

- Referral Date
- Decision To Treat (DTT)
- Earliest Clinically Appropriate Date (ECAD)
- First Radiotherapy Treatment Date

## Q1. What was the mean and median time from Decision To Treat to commencement of radiotherapy?

### FOI Question

For lymphoma patients receiving radiotherapy, what was the mean and median number of days between Decision To Treat and first radiotherapy treatment?

### Query
``` SQL
WITH lymphoma AS (
    SELECT
        ep.radiotherapy_episode_identifier,
        ep.dtt_date,
        rt.first_treatment_date
    FROM rtds.fact_episode ep
    INNER JOIN mart.vw_rt_patient_starts rt
        ON ep.radiotherapy_episode_identifier =
           rt.radiotherapy_episode_identifier
    WHERE ep.disease_group = 'Lymphoma'
      AND rt.first_treatment_date >= DATE '2024-04-01'
      AND rt.first_treatment_date < DATE '2025-04-01'
      AND ep.dtt_date IS NOT NULL
)
SELECT
    COUNT(*) AS episodes,
    ROUND(
        AVG(first_treatment_date - dtt_date),
        1
    ) AS mean_dtt_days,
    PERCENTILE_CONT(0.5)
        WITHIN GROUP (
            ORDER BY first_treatment_date - dtt_date
        ) AS median_dtt_days
FROM lymphoma;
```

### Output
- Number of episodes analysed
- Mean DTT → RT start interval
- Median DTT → RT start interval

## Q2. What percentage of patients started treatment within 31 days?
### FOI Question

What percentage of lymphoma patients commencing radiotherapy during November 2024, December 2024 and January 2025 started treatment within 31 days of Decision To Treat?

### Query
``` SQL
WITH lymphoma AS (
    SELECT
        ep.radiotherapy_episode_identifier,
        ep.dtt_date,
        rt.first_treatment_date
    FROM rtds.fact_episode ep
    INNER JOIN mart.vw_rt_patient_starts rt
        ON ep.radiotherapy_episode_identifier =
           rt.radiotherapy_episode_identifier
    WHERE ep.disease_group = 'Lymphoma'
      AND rt.first_treatment_date >= DATE '2024-11-01'
      AND rt.first_treatment_date < DATE '2025-02-01'
      AND ep.dtt_date IS NOT NULL
)
SELECT
    DATE_TRUNC(
        'month',
        first_treatment_date
    )::date AS month,

    COUNT(*) AS patients,

    COUNT(*) FILTER (
        WHERE first_treatment_date - dtt_date <= 31
    ) AS achieved,

    ROUND(
        100.0 *
        COUNT(*) FILTER (
            WHERE first_treatment_date - dtt_date <= 31
        )
        / COUNT(*),
        1
    ) AS percentage_achieved
FROM lymphoma
GROUP BY 1
ORDER BY 1;
```

### Output

For each month:

- Number of patients
- Number achieving the 31-day standard
- Percentage compliance

## Q3. Which patients require Somerset review for 62-day pathway analysis?
### FOI Question

Provide patient identifiers so that Cancer Services can calculate 62-day performance from Somerset Cancer Registry data.

### Query
``` SQL
SELECT
    dp.nhs_number,
    ep.radiotherapy_episode_identifier,
    ep.diagnosis_icd,
    rt.first_treatment_date
FROM rtds.fact_episode ep
INNER JOIN mart.vw_rt_patient_starts rt
    ON ep.radiotherapy_episode_identifier =
       rt.radiotherapy_episode_identifier
INNER JOIN rtds.dim_patient dp
    ON ep.patient_sk = dp.patient_sk
WHERE ep.disease_group = 'Lymphoma'
  AND rt.first_treatment_date >= DATE '2024-04-01'
  AND rt.first_treatment_date < DATE '2025-04-01'
ORDER BY rt.first_treatment_date;
```

### Output

Provides:

- NHS Number
- RT Episode Identifier
- Diagnosis Code
- First Treatment Date

This extract can be supplied to Cancer Services for:

- Urgent referral date retrieval
- 62-day pathway calculation
- Somerset validation
- Breach reason investigation

## Q4. Which patients breached the 31-day standard?
### Purpose

Creates a review list for manual ARIA validation and breach reason identification.

### Query
``` SQL
WITH lymphoma AS (
    SELECT
        ep.patient_sk,
        ep.radiotherapy_episode_identifier,
        ep.diagnosis_icd,
        ep.dtt_date,
        ep.ecad,
        rt.first_treatment_date,
        rt.first_treatment_date - ep.dtt_date AS dtt_days,
        rt.first_treatment_date - ep.ecad AS ecad_days
    FROM rtds.fact_episode ep
    INNER JOIN mart.vw_rt_patient_starts rt
        ON ep.radiotherapy_episode_identifier =
           rt.radiotherapy_episode_identifier
    WHERE ep.disease_group = 'Lymphoma'
      AND rt.first_treatment_date >= DATE '2024-04-01'
      AND rt.first_treatment_date < DATE '2025-04-01'
)
SELECT
    dp.nhs_number,
    l.radiotherapy_episode_identifier,
    l.diagnosis_icd,
    l.dtt_days,
    l.ecad_days,
    CASE
        WHEN l.dtt_days > 31
         AND l.ecad_days <= 31
            THEN 'Possible planned delay'
        WHEN l.dtt_days > 31
         AND l.ecad_days > 31
            THEN 'Possible genuine breach'
        ELSE 'Within standard'
    END AS review_category
FROM lymphoma l
INNER JOIN rtds.dim_patient dp
    ON l.patient_sk = dp.patient_sk
WHERE l.dtt_days > 31
ORDER BY l.dtt_days DESC;
```

### Output

Produces a patient-level review list including:

- NHS Number
- Episode Identifier
- DTT delay
- ECAD delay
- Suggested review classification

Used to support manual review within ARIA and identify:

- Capacity delays
- Planning delays
- Patient choice
- Sequential treatment pathways
- Clinical factors


## Important Caveats
## Lymphoma Cohort Definition

The RTDS dataset currently maps lymphoma episodes using:

    C81.9
    C85.0
    C85.1
    C85.9


The dataset does not reliably distinguish:

- Aggressive / high-grade NHL
- Indolent NHL

Therefore FOI responses should note that the analysis uses the broader Lymphoma cohort unless a more granular diagnosis source is available.

### Referral Date

The RTDS referral_date field is available and useful operationally; however, Cancer Services should validate 62-day pathway calculations using Somerset where a statutory performance measure is required.

### ECAD vs DTT

Where:

    DTT → Treatment > 31 days
    ECAD → Treatment ≤ 31 days


the delay may represent:

- Patient choice
- Planned chemotherapy
- Planned surgery recovery period
- Other clinically appropriate sequencing

These cases should not automatically be interpreted as operational delays.
