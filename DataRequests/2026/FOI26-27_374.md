Breast Cancer  = ICD-10 C50* and D05*

## Determine relevant schema

``` SQL
SELECT
    table_schema,
    table_name,
    ordinal_position,
    column_name,
    data_type
FROM information_schema.columns
WHERE table_schema IN ('raw', 'staging', 'sact', 'mart')
  AND (
        table_name ILIKE '%sact%'
        OR table_name ILIKE '%regimen%'
        OR table_name ILIKE '%administr%'
        OR table_name ILIKE '%drug%'
      )
ORDER BY
    table_schema,
    table_name,
    ordinal_position;
```

## Final query

``` SQL
SELECT
    regimen,
    COUNT(DISTINCT patient_sk) AS patients
FROM sact.fact_regimen
WHERE start_date_of_regimen >= DATE '2026-03-01'
  AND start_date_of_regimen <  DATE '2026-06-01'
  AND (
        primary_diagnosis LIKE 'C50%'
        OR primary_diagnosis LIKE 'D05%'
      )
GROUP BY regimen
ORDER BY regimen;
```
